# Sumi Note（墨ノート）

Galaxy Tab S11 と S ペンで**受験勉強をする**ための手書きノートアプリ。
Samsung Notes にない「覚える・解く・復習する」機能を中心に作った。
**APK（Android アプリ）** として入れるのが本命。同じものを PWA（Chrome からインストールする Web アプリ）としても使える。

## インストール

### A. APK（おすすめ）

1. Galaxy Tab で **https://github.com/S70RM3892/Note/releases/latest/download/SumiNote.apk** を開いてダウンロード。
2. ダウンロードした `SumiNote.apk` をタップ →「この提供元のアプリを許可」→ インストール。
3. 既定ブランチへの push ごとに CI が自動でビルドして Releases に置く。更新は同じ手順で上書きインストール（**下の署名鍵を設定してあれば**ノートはそのまま）。

APK 版だけの機能：
- **スキャナーで撮影**（Google ML Kit ドキュメントスキャナー）：紙の輪郭を自動検出して撮影・台形補正・影や指の除去まで端末内で済ませ、そのままベクター化に回す。カメラ権限はアプリに不要（Google Play 開発者サービスが担当）。
- **低遅延ペン**：書いている線は Android が直接、フロントバッファ（画面に出ている最中のバッファ）に描く。Web の描画パイプラインを待たないのでペン先への追従が速い。ペンのサンプルは1フレームにまとめずに届いた瞬間に受け取る。書いている間は線を**足すだけで何も消さない**（先読みの線を描いて消し直すと、画面に出ている途中のバッファが一瞬白く抜けてギザギザに見えるため、先読みはやめた）。ペンを置いてノートに確定した線が画面に出たあと、まとめて1回で差し替える。ノート側も拡大率ぴったりの解像度で描くので、差し替えで線の見た目は変わらない。おかしければ 設定 → ペン →「低遅延ペン」をオフ。
- **診断ログ**（設定 → データ → 診断ログ）：アプリが落ちたとき・表示エンジンが落ちたとき・低遅延ペンでエラーが起きたとき・画面のスクリプトでエラーが起きたときの記録。落ちた次の起動で「前回アプリが落ちた」と出る。不具合を伝えるときは「コピー」か「共有」でそのまま送れ（ノートの中身は入っていない）。
- **S ペンのボタンを押しながら書くと消しゴム**（ブラウザ版では不可。下の「S ペンの設定のコツ」）。
- **S ペンのボタンをクリック**（書かずに押して0.4秒以内に離す）で「元に戻す」「ペン⇄マーカー」「ペン⇄消しゴム」を選べる（設定 → ペン。初期値は何もしない）。押したまま書けば今まで通り消しゴム。
- **手書き文字認識**（Google ML Kit Digital Ink、日本語）：設定 → 手書き文字認識 → モデルをダウンロード（約20MB、1回だけ。以後は端末内で動きネット不要）。ライブラリを開いている間に書いたページを少しずつ読み取り、検索欄で手書きの言葉が「手書き」として見つかる。投げ縄で囲んで「テキストに変換」→ 読みを直す／候補をタップ →「置き換え」（元に戻すで手書きに戻る）か「コピー」。
- **自動バックアップ**：設定 → 自動バックアップ →「フォルダを選ぶ」。以後ライブラリを開いたとき1日1回、全ノートを `sumi-backup-日付.sumi` で書き出し、最新10個を残す。Google ドライブのフォルダを選べば端末ごと失くしても残る。
- **就寝・復習のお知らせ**（設定 → お知らせ、オフが初期値）：就寝時刻の30分前に「区切りをつけろ」、就寝時刻に「寝ろ」と通知。毎日決めた時刻（初期値 19:00）に「今日の復習 N ページ」と一番近い入試までの日数を通知。アプリを閉じていても届き、再起動後も続く。時刻ちょうどの通知には特別な権限（正確なアラーム）が要るので使わず、Android の普通のアラームで「時刻の5分前から10分の間」に出す（Android 12 以降は窓が最低10分。[Android Developers: Schedule alarms](https://developer.android.com/develop/background-work/services/alarms)）。初めてオンにすると通知の許可を聞かれる。
- **ホーム画面のショートカット**：アプリのアイコンを長押し →「新しいノート」「スキャン」「今日の復習」に直行。
- **集中モード**：過去問タイマーが動いている間は画面を消さない。設定でオンにすると、タイマー開始でアプリを画面に固定（Android の「アプリ固定」。確認が出る）し、一時停止・終了で解除。
- 戻るジェスチャーでメニュー → ダイアログ → ライブラリの順に閉じる。全画面表示（端からスワイプでバーが一時的に出る）。
- 他のアプリの「共有」「アプリで開く」から PDF・画像を受け取って新しいノートにする。PDF/バックアップは「他のアプリに送る」か「ファイルとして保存」を選べる。

#### 署名鍵（最初に1回だけ設定しておけ）

Android は**同じ鍵で署名された APK しか上書き更新させない**。鍵を設定していない間は CI がビルドのたびに使い捨ての鍵で署名するので、更新するには「バックアップを書き出す」→ アンインストール → 新しい APK → 取り込み が必要になる（アンインストールでノートは消える）。上書き更新できるようにするには、PC（または Termux）で鍵を作り、リポジトリの **Settings → Secrets and variables → Actions** に4つ登録する：

```bash
keytool -genkeypair -keystore sumi-release.jks -storetype PKCS12 -alias sumi \
  -keyalg RSA -keysize 4096 -validity 36500 -dname "CN=Sumi Note"
base64 -w0 sumi-release.jks   # 出力全体を SUMI_KEYSTORE_B64 に
```

| Secret | 値 |
|---|---|
| `SUMI_KEYSTORE_B64` | 上の base64 |
| `SUMI_KEYSTORE_PASSWORD` | keytool で決めたパスワード |
| `SUMI_KEY_ALIAS` | `sumi` |
| `SUMI_KEY_PASSWORD` | 同じパスワード（PKCS12 は共通） |

`sumi-release.jks` とパスワードはリポジトリに入れず、自分だけが見られる場所に保管しろ（なくすと次から上書き更新できない。公開リポジトリに置くと誰でも「更新版」を名乗る APK を作れてしまう）。

### B. PWA（Chrome から）

1. GitHub のこのリポジトリで **Settings → Pages → Build and deployment → Source を「GitHub Actions」** にする。
2. **Actions タブ → 「CI & Deploy」の最新の実行 → Re-run all jobs**（以後はリポジトリの既定ブランチへの push で自動的にテスト・公開される）。
3. Galaxy Tab S11 の **Chrome** で `https://s70rm3892.github.io/Note/` を開く。
4. Chrome のメニュー（︙）→「**アプリをインストール**」（または「ホーム画面に追加」）。
   以後はホーム画面のアイコンから全画面で起動し、**オフラインでも動く**。更新があると画面上部に「更新」ボタンが出る。

> 低遅延描画（`desynchronized` キャンバス）など Chrome の機能を前提に作っている。Chrome で使え。

> APK と PWA は保存場所が別。PWA で書いたノートは「バックアップを書き出す」→ APK で取り込む。

### S ペンの設定のコツ
- **ボタンを押しながら書く → 消しゴム**（設定で「投げ縄」にも変更可）。**APK 版のみ**：Chrome（と PWA）はボタンを押したままのペン操作を文字選択に使ってページに渡さないので、ブラウザでは効かない。APK はその操作を消しゴムのペンとしてページに渡し直している。
- ペンを画面に近づけてボタンを押すと **Air command** が開く端末設定になっていることがある（Samsung の機能）。邪魔なら端末の S ペン設定で Air command をボタンで開かないようにする。

## 使い方

### ジェスチャー
| 操作 | 動作 |
|---|---|
| S ペン | 書く（パームリジェクションは下記） |
| 指1本ドラッグ | スクロール（慣性あり） |
| 指2本ピンチ | 拡大縮小（100% で軽く吸着） |
| **指2本タップ / 3本タップ** | 元に戻す / やり直し |
| 指1本タップ（テープの上） | 暗記テープをめくる／戻す |
| ペンを止める（約0.45秒） | 図形補正。直線は止めた後もペンを動かすと端点が追従 |
| 同じツールをもう一度タップ | ツールの詳細設定（ペン種類・太さ・色・消しゴムモードなど） |

指で書きたい場合は 設定 → 指で書く。

**パームリジェクション**（何重にもかけてある）：
1. 指・手のひらでは**そもそも書けない**（初期設定）。インクが出るのは S ペンだけ。
2. ペンが画面の上に浮いている間と、離してから 0.45 秒は**指のタッチを全部無視**（スクロールもしない）。
3. ペンが触れた瞬間、進行中の指のスクロール・ピンチを打ち切る。
4. ペンを使った直後 0.9 秒は2本指・3本指タップ（元に戻す/やり直し）を受け付けない（手のひらが2点に割れて誤 Undo になるのを防ぐ）。
5. 接触面が大きいタッチ（手のひら）は無視。OS がキャンセルしたタッチ（`pointercancel`）も破棄。

### ツール
- **お気に入りペン**：ペンの種類・色・太さの組み合わせをツールバーの ☆ で登録（8本まで）。タップ1回でそのペンに戻る。外すときはペンをもう一度タップ → お気に入りペンの ×。
- **線の処理（速記対応）**：ペンの入力は Google の Ink Stroke Modeler と同じ方式で整える。ゆっくり書くときだけ手ぶれを平均し、速く書くときは生の位置に従う。1秒480点以上に補間したうえで、ペン先をバネでつながれた重りとして動かすので、速く書いた「の」もカクカクせず滑らかになる。書き終わりはペン先がバネに沿って離した位置まで追いつく（直線でワープしない）ので、はね・はらいの形が残る。バネは元の設定より硬くしてあり、速く書いた「く」「レ」の角も丸まらない（750 px/s のジグザグで角のずれ 2.6 px）。設定の「手ぶれ補正」は、ゆっくり書くときの平均の強さ。
- **ペン**：太さが完全に均一な**ライナー**だけ（筆圧で太さは変わらない）。太さと色を選ぶ。以前のペン（ボールペン・万年筆など）で書いた線はそのまま残る。
- **ペン先のプレビュー**：S ペンを画面に近づけると、書く位置にペンの色と太さの点が出る（消しゴムは円。ボタンを押しながら近づけると消しゴムの円になる）。
- **ページの自動追加**：最後のページの下の方（下 18%）まで書くと次の白紙ページが足される。PDF のページでは足さない。元に戻す1回で、その線と足したページが一緒に消える。
- **マーカー**：インクの下に塗られる（乗算合成）。一番右の濃い緑は **暗記マーカー**：黒字の上に引くと赤シートで字が消える。パレットの「直線」にすると**まっすぐなマーカー**になる（0°・45°・90° に吸着）。教科書の行に引くとき用。
- **消しゴム**：部分消し（線を途中で切る）/ 線ごと消し。暗記テープも消せる。
- **投げ縄**：囲んで選択、またはタップで1つ選択。ドラッグで移動、角で拡大縮小、上の丸で回転（15°刻みで吸着）、**別のページへドラッグすると移動**。メニューから削除・切り取り・コピー・複製・色変更・**太さ変更**（細・標準・太・極太。書いたあとで強調したい線を太くする）・**テープで隠す**・**図形に整える**（選んだ手描きの線のうち、直線・円・楕円・多角形・折れ線と読めるものをきれいな図形に置き換える。元に戻す1回で戻る）。
- **テキスト**：タップして入力（キーボード・S ペンの手書き入力どちらも可）。入力中は下に**記号パレット**（√ π θ Σ ∫ ∞ ± ≠ ≦ ≧ ≒ → ⇔ ⇒ ∴ ∵ ∈ ⊂ ∠ △ ⊥ ∥ ° ² など）が出て、ワンタップで入る。
- **日付スタンプ**（⋯ →「今日の日付を入れる」）：ページ右上に「2026/10/26(月)」のように入る。何度押しても重ならない。
- **投げ縄で何もない所（PDF の問題など）を囲む**と、その範囲に対して：**まちがいノートへ**（下記）／**画像でコピー**（PDF の図や写真を切り抜いて、別のページで投げ縄 →「貼り付け」）／**テープで隠す**（PDF の答えをそのまま暗記テープで隠す）。
- **まちがいノート**：投げ縄で問題（と自分の答案）を囲んで「まちがいノートへ」。「まちがいノート」に、出典（ノート名・ページ・日付）、問題の切り抜き（固定済み）、選んだ手書き（ベクターのまま）、「▼ 解き直し」の余白が入ったページができ、**翌日から復習に出る**。
- **固定**：投げ縄で選んで「固定」。固定したものは投げ縄・消しゴム・テキストに反応せず、上から普通に書き込める。投げ縄で固定したものをタップすると「固定を解除して選択 / このページの固定をすべて解除」が出る（右上に錠前マーク）。**挿入した画像・スキャンは、位置を決めて外をタップした時点で自動で固定**（設定で切替可）。
- **暗記テープ**：答えの上をなぞって貼る。指でタップするとめくれる。

### ページ
- 縦スクロール / 横めくり（メニューで切替。横めくりは指を離すとページに吸着）。
- テンプレート：無地 / 横罫 / 方眼 / ドット / コーネル / 左右分割 / **方眼 1cm強調** / **英語4線** / **原稿用紙 400字**（20×20、柱つき。A4 横で1マス約9mm）/ **マークシート**（共通テスト形式の解答欄：解答番号ごとに 1〜9・0 の楕円。A4 縦で2列×35問。マークの練習と自己採点用）/ **六角方眼（構造式）**（頂点が上の六角形の格子。線が120°で交わるので、ベンゼン環や骨格構造式がそのまま描ける）、間隔 4〜10mm、紙色 4種、サイズ A4・B5・A4横・16:10。PDF に書き出しても罫線はベクターのまま。
- **解き直し**（⋯ →「白紙にして解き直す」）：ページの手書きを消して白紙に戻す（PDF・写真・文字と、固定した線は残る）。消した答案は「前回の答案」として残り、解き直したあと ⋯ →「前回の解答を薄く重ねる」で薄い色で下に表示されるので、今回の答えと見比べられる。元に戻す1回で前の答案に戻る。
- **しおり一覧（全ノート）**：ライブラリに、全部のノートのしおりが新しい順に出る（5件。それ以上は「すべて」）。タップでそのページに直行。
- ページ一覧（ツールバーの「1 / 5」のようなページ表示をタップ）：タップで移動、ドラッグで並べ替え、⋯ で挿入・複製・削除・復習に追加・しおり・**ほかのノートへコピー／移動**（相手のノートの最後に入る）。各ページに**そのページで書いていた時間**（1分以上）が出るので、過去問の大問ごとにページを分ければ何分かかったかが残る。PDF にしおりがあれば上に**目次**が出て章へ飛べる。
- **しおり**：ページ表示の右のリボンをタップすると今のページにしおり。ページ一覧の一番上に一覧が出て、タップで飛ぶ。名前は鉛筆ボタンで付ける（付けなければページの最初の文字が名前になる）。しおりの名前は検索でも見つかる。
- **ページの履歴**（⋯ →「このページの履歴（復元）」、ページ一覧の ⋯ →「履歴から復元」）：書いている間10分ごと（と、別の日に開いて最初に書いたとき）、**全消去や大きく消したときは必ず**、その前の状態が残る（1ページ30個まで）。サムネイルを選ぶとその時点に戻る。ノートを閉じたあとで「消さなきゃよかった」に効く。
- **全文検索**：ライブラリの検索欄に2文字以上入れると、しおりの名前・取り込んだ PDF の本文・テキストツールの文字（APK では読み取った手書き文字も）からページを探す（全角/半角は区別しない）。
- 画像の挿入・カメラ撮影、PDF ページの挿入。
- **関数グラフを挿入**（⋯ メニュー）：`y = x^2 - 2x - 3` のように1行に1本（最大4本）書くと、座標軸・矢印・目盛り・O・x・y の入ったグラフができる。手で書く書き方がそのまま通る：`2x²`、`(x+1)(x-2)`、`sin 2x`、`sin^2 x`、`|x-1|`、`√x`、`e^-x`、`log_2 x`（底なしの `log` は 数III の自然対数）。範囲は `-2π` や `1/2` でも可。オプション：縦横同じ縮尺／方眼／目盛りの数字／x 軸を π 単位。tan x や 1/x の漸近線ではつながず切り、√x や log x は定義域の端から描く。**できるのは普通の線と文字**なので、上から書き込む・消しゴムで一部消す・投げ縄で動かす／拡大縮小がそのままできる（元に戻す1回で全部消える）。プリセット：放物線・三角関数・指数対数・分数関数・座標軸だけ。
- **写真をベクターで取り込む**（ツールバーのスキャンアイコン / ライブラリの「スキャン」）：撮影（APK はスキャナー）または画像を選ぶ → 四隅を合わせる（自動検出あり）→ 白黒ベクター / カラーベクター / 写真のまま を選び、「線の拾い方」で薄い鉛筆まで拾うか調整 → **このページに配置**（大きさを決めて外をタップで固定）／**PDF で保存**（ベクター PDF）／**新しいノートにする**。影・照明ムラは自動で消え、赤ペンなどの色は別レイヤーになる（赤シートも効く）。
- **参照ビュー**（ツールバーの左右分割アイコン）：左に別のノート（過去問 PDF など）を読み取り専用で表示。左側はペンでもスクロールでき、書き込まれない。境目をドラッグで幅を変更。ノートごとに記憶され、次に開いたときも復元される。

## 受験ハブ（ノートの外側）

ライブラリ上の「受験ハブ」。ノートでは足りない、合格までの戦略・計画・暗記・情報Ⅰ・体調の道具。数字はすべて公式の資料から取り、各ページに出典を付けた。データは `.sumi` バックアップに入る（取り込むと端末にないものだけ足す。音声ファイルは入らない）。

### 合格戦略
- **合格点シミュレーター**：共通テスト9科目の素点を入れると、京大工学部の配点で換算する（共通テスト225＝国語25・地歴公民50・数学25・理科25・外国語50・情報50。英語はR100+L100の200点で利用）。二次（国語100・数学250・理科250・外国語200）の目標点を足した合計を、情報学科の合格者の点と比べる。令和8年度は最低点645.49・平均694.29、令和7年度は最低点707.52・平均748.86（どちらも1025点満点）。「この共通テストなら、二次で何点要るか」も出る。出典は令和9年度 京都大学入学者選抜要項と京都大学「入学者選抜実施状況」。換算は素点を配点に比例させた計算で、端数の扱いは公表されていない。
- **模試の記録**：共通テスト型・京大型・その他。科目別の得点・満点・偏差値・判定・メモを記録する。得点率の推移をグラフにし、いちばん低い科目を出す。共通テスト型は京大工学部の換算点も出る。
- **入試日程・時間割**：令和9年度の公式日程。共通テストの受験票の取得（12/4から）、共通テスト（1/16・1/17。時間割は工学部の受験者向け）、京大の出願（1/25〜2/3）、第1段階選抜の発表（2/10）、個別試験（2/25 国語9:30〜11:00・数学13:30〜16:00、2/26 英語9:30〜11:30・理科13:30〜16:30）、合格発表（3/10）。各科目の「タイマー」で、本番と同じ時間の過去問タイマーになる。
- **持ち物チェック**：共通テストは令和9年度「受験案内」の「机の上に置けるもの」どおり（黒鉛筆はH・F・HB、時計は計時機能だけのもの等）。試験中に使えないものの注意つき。京大二次は自分で足していく。

### 計画と振り返り
- **参考書の進捗**：全部の量・終わった数・締切を入れると、1日に何問やれば間に合うかを出す。最近2週間のペースで「いつ終わるか」と「間に合うか」も出る。+1 ボタンで記録する。
- **過去問の進捗表**：年度×科目の表に得点を入れる。色は得点率で、緑が70%以上、黄が50%以上。どの年度を解いたかと科目ごとの平均がわかる。
- **週間レポート**：1週間の学習時間（前の週と比較・教科別）、過去問、模試、参考書の進み、単語帳、ミス、睡眠、振り返りをまとめる。テキストでコピーして先生に送れる。
- **1日の振り返り**：うまくいったこと・うまくいかなかったこと・明日の最優先、の3行。明日の最優先は「今日やること」に入る。就寝時刻のバナーに「振り返り」ボタンがある。

### 覚える・解く
- **ミス分析**：まちがいノートに送ると「なぜまちがえた？」と聞かれる（計算ミス・ケアレス・読み違い・知識・方針・時間）。科目はフォルダ名が初期値。種類別・科目別の傾向が出る。
- **単語帳**：表と裏のカード。忘れかけた頃に出る（ページの復習と同じ間隔の伸ばし方で、新しいカードは1日20枚まで）。Excel やスプレッドシートの2列（タブ・CSV・「：」区切り）をそのまま貼って追加できる。CSV で書き出せる。英語は🔊で読み上げる。
- **英文の読み上げ**：英文を貼ると、全部または1文ずつ読み上げる。速さは ×0.6〜×1.2。ノートの中でも、投げ縄でテキストを選ぶと「読み上げ」が出る。APK は Android の音声合成を使う。
- **リスニング**：音声ファイル（共通テストのリスニング等）を入れて、速さ ×0.75〜×1.5（声の高さは変わらない）、5秒戻し・送り、A→B の区間リピートで聞く。止めた位置を覚える。音声は端末の中にだけ保存する。
- **質問リスト**：先生に聞くことを溜める。ノートの ⋯ →「質問リストに入れる」でページごと入り、「ページへ」で戻れる。

### 情報Ⅰ
- **プログラム表記の実行**：大学入試センターの「共通テスト用プログラム表記の例示」の書き方をそのまま実行する。変数・配列（Data[2,4]）、+ - * / ÷（商）%（余り）**、and/or/not、要素数・整数・乱数・表示する、もし/そうでなくもし/そうでなければ、〜の間繰り返す、〜ずつ増やしながら（減らしながら）繰り返す、【外部からの入力】、#コメントが使える。ブロックは ｜ と ⎿（または字下げ）で書く。問題の行番号「( 1 )」は貼ったままで構わない。**トレース表**には1ステップごとの行・条件の真偽・全変数の値が出て、変わった値に色が付く。エラーは「2行目: 変数 z にまだ値が入っていない」のように日本語で出る。｜ ⎿ や「ならば:」はボタンで入る。例示の二分探索は、センターの資料と同じ結果になることをテストで確かめた。問題文の中で定義される独自の関数は使えない。
- **基数変換・論理回路**：2・8・10・16進の変換、2の補数（4/8/16ビット、両方向）、AND/OR/XOR、文字の Unicode と UTF-8、論理式（and/or/not、∧∨¬）の真理値表。

### 体調・睡眠
- **睡眠記録**：朝ライブラリを開くと「昨夜の睡眠」を聞かれ、1タップで記録できる。直近7日の平均を、高校生の目安8〜10時間と比べる。寝る時刻・起きる時刻のばらつきと、休日の起床が平日よりどれだけ遅いかも出る（週末も同じ時刻に起きるのが推奨）。出典は厚生労働省「健康づくりのための睡眠ガイド 2023」。
- **仮眠タイマー**：10・15・20分。暗い画面で待ち、時間で音と振動。午後の昼寝は眠った時間が10分程度のものが最もすっきりし、30分ではかえってぼんやりした（Brooks & Lack, *Sleep* 29(6), 2006）。
- **目の休憩**：ペンで書き続けて30分で「小休止」、60分で「10〜15分休め」と知らせる。10分書かなければ数え直す。過去問タイマー中は出さない。目安は厚生労働省「情報機器作業における労働衛生管理のためのガイドライン」（一続きの作業は1時間以内、次まで10〜15分休む、途中で1〜2回の小休止）。

### Android（APK）
- **ホーム画面のウィジェット**「入試カウントダウン」：次の入試までの日数・今日の学習時間・今日の復習ページ数。日数は日付が変わると自動で減る。
- **タイマー中のおやすみモード**：受験ハブ →「Android 連携」でオンにする（初回は Android の設定で許可）。過去問タイマー・ポモドーロが動いている間は通知を止め、アラームだけ鳴る。止めると元の設定に戻す。

## 受験での使い方（京大工学部情報学科を想定）

ライブラリには **今日やること**（未完了は翌日に持ち越し、済んだものは翌日消える）と **学習の記録**（16週間のヒートマップ・連続日数・7日/30日の合計・**7日の教科別内訳**・**今週と先週の同じ曜日までの比較**。設定で**1日の目標**（1〜5時間）を決めると「今日の学習時間」に進み具合のバーが出る。ペンで書いていた時間を数えている。教科はフォルダ単位なので「数学」「英語」…とフォルダを作ってノートを入れておけ）も出る。

ライブラリ左上に**入試までの日数**が出る。初期値は 2027年度入試：共通テスト本試験 **2027年1月16日（土）・17日（日）**、京大 一般選抜（前期）**2027年2月25日（木）・26日（金）**（令和9年度 京都大学入学者選抜要項）。受験年度が違うなら 設定 → 入試日 で直せ。

1. **過去問演習**：問題 PDF を「PDF取込」→ 解答用ノートを開いて**参照ビューで問題 PDF を左に表示** → タイマーで「京大 数学 150′」等を選んで開始（開始するとツールバーに格納される）→ 右に解答を書く。PDF に直接書き込んでもいい。終わったら「PDFで書き出し」。
   - 大問を解き終わるたびに「大問N 終わり」（ツールバーに格納中は「大問N✓」）を押すと、**大問ごとの所要時間**が記録され、ライブラリの過去問タイマー欄に「大問 31/42/25分」のように残る。時間配分の反省に使え。
   - **時間配分ガイド**：開始前に「大問の数」（3〜6）を選ぶと、タイマーに「大問1 目安 23:20・あと 05:12」のように今の大問の目安と残りが出る。目安を過ぎると赤字で「超過」。目安は（試験時間 − 見直し10分）÷ 大問の数（1時間未満の試験は見直し分を取らない）。
   - **結果をページに書く**：タイマーの「結果をページに記入」で、今開いているページの左上に「2026/10/26(月) 京大 数学  142分 / 150分  大問 31 / 42 / 25分」が文字で入る。答案と一緒に残せ。
   - **ポモドーロ**：タイマーの「ポモドーロ 25′」で 25分集中 → 5分休憩 を自動で繰り返す（4回ごとに15分休憩。Francesco Cirillo のポモドーロ・テクニックの基本形）。区切りで音と振動、今日何回目かを表示。過去問ではなく普段の演習用。
   - プリセットは令和7年度 一般選抜 学生募集要項の工学部の個別学力検査の時間（国語90分・数学150分・外国語120分・理科180分）。**毎年の募集要項で必ず確認しろ。**
2. **間違えた問題**：問題 PDF の問題を投げ縄で囲む →「まちがいノートへ」。翌日、3日後…と復習に出るので、解き直し欄に何も見ずに解け。
3. **暗記**：答えはオレンジ（#ff6a00）で書く → 赤シートで隠して自分をテスト。教科書の写真を挿入して暗記テープ／暗記マーカーを使うのも有効。
4. **復習**：覚えたいページを「復習に追加」→ ライブラリの「今日の復習」から出題。テープは全部隠れた状態で出るので、答えを思い出してからめくり、「もう一回 / 難しい / 普通 / 簡単」で自己採点。間隔は自動で伸びる（SM-2 系のアルゴリズム）。
5. **寝る**：就寝時刻（初期値 23:00）を過ぎると画面左下に警告が出て、暖色フィルターがかかる。設定で **就寝ロック** をオンにすると、就寝時刻の15分後から起床時刻まで画面が閉じて書けなくなる（延長は「5秒長押しで15分」を1晩2回まで。使い切ったら「今夜だけ解除」と入力しない限り開かない。過去問タイマー中はロックしない）。自分の意志に頼るな、仕組みで寝ろ。睡眠中に記憶が定着することは研究でも示されている（Diekelmann & Born, *Nature Reviews Neuroscience* 11, 114–126, 2010）。

## データとバックアップ

- ノートは**この端末の中（APK はアプリ内、PWA は Chrome の IndexedDB）にだけ**保存される。自動保存。
- APK は 設定 → 自動バックアップ でフォルダを選んでおけば毎日勝手に書き出す。
- アプリのアンインストールや「サイトデータの削除」で**全部消える**。ライブラリ右上 ⋯ →「バックアップを書き出す」で `.sumi` ファイルを Google ドライブ等に保存しておけ。指定日数（初期値7日）バックアップしていないとライブラリに警告が出る。
- `.sumi` はノート単位でも書き出せる（共有用）。取り込みは ⋯ →「バックアップ / .sumi を取り込む」。
- Android の共有メニューから PDF・画像を Sumi Note に送ると、新しいノートとして取り込まれる（APK は「アプリで開く」も可）。
- **CSV**：ライブラリの「学習の記録」の「CSV」で日別の学習時間（合計と教科別、分）、「過去問タイマー」の「CSV」で過去問の記録（日時・科目・予定と実際の時間・大問ごとの時間）を書き出す。Excel・Google スプレッドシートでそのまま開ける（文字化けしない UTF-8 BOM 付き）。

## 開発

```bash
npm ci
npm run dev          # 開発サーバー
npm test             # ユニットテスト（Vitest）
npm run test:e2e     # E2E（Playwright。Tab S11 相当の 1280×800・DPR2、S ペン/マルチタッチを CDP でエミュレート）
npm run build        # dist/ に出力（Service Worker の precache 一覧も生成）

# APK（JDK 17+ と Android SDK。ANDROID_HOME を設定）
npm run build && cd android && ./gradlew assembleRelease   # → app/build/outputs/apk/release/app-release.apk
```

構成：

- `src/core` — データモデル、筆跡ジオメトリ（筆圧円の外接線による輪郭）、ストロークモデラー（`modeler.ts`、Ink Stroke Modeler の移植。APK 側の `Modeler.kt` と同じ計算をテストで突き合わせている）、図形認識、部分消しゴム、復習スケジューラ、Undo
- `src/editor` — ビューポート、描画（ページ単位のビットマップキャッシュ＋深いズーム時のベクター描画、PDF の部分高解像度描画）、低遅延ライブレイヤー（`desynchronized` キャンバス＋予測点）、入力（パームリジェクション、ジェスチャー）、各ツール
- `src/store` — IndexedDB、設定、バックアップ（zip）
- `src/pdf` — pdf.js（CJK cmap 同梱でオフライン表示）、pdf-lib による書き出し
- `src/study` — 赤シート、タイマー、学習時間
- `src/hub` — 受験ハブ：共通テスト用プログラム表記のインタプリタ（`dncl.ts`）、京大工学部の配点・日程（`exam.ts`、公式資料の数字）、模試・参考書・過去問（`plan.ts`）、単語帳（`cards.ts`）、睡眠・休憩（`health.ts`）、各ページ（`tools/`）
- `src/app` — 画面（ライブラリ、エディタ、ダイアログ、スキャン）
- `src/scan` — 写真 → ベクター（Web Worker）：射影変換、紙の色の推定による影除去、ヒステリシス二値化、色相ヒストグラムで色分け、輪郭追跡（穴あり）→ 単純化・平滑化 → SVG パス
- `src/platform.ts` — APK のネイティブ連携（`window.SumiNative`）。ブラウザでは何もしない
- `android/` — Kotlin の薄いシェル：低遅延ペン（`WetInk.kt`、`CanvasFrontBufferedRenderer` に線を足していくだけ）、WebView（`WebViewAssetLoader` で `https://appassets.androidplatform.net` から dist を配信）、ML Kit ドキュメントスキャナー、保存/共有、「アプリで開く」、S ペンのボタン、戻る、読み上げ（`Speech.kt`）、ウィジェット（`CountdownWidget.kt`）、おやすみモード（`Dnd.kt`）

CI（`.github/workflows/ci.yml`）は型チェック → ユニット → ビルド → E2E を実行し、既定ブランチなら GitHub Pages に公開、APK をビルドして Releases（タグ `apk`）に置く。
