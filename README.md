# Sumi Note（墨ノート）

Galaxy Tab S11 と S ペンで**受験勉強をする**ための手書きノートアプリ。
Samsung Notes にない「覚える・解く・復習する」機能を中心に作った PWA（インストール型 Web アプリ）。
ストアを使わずに Chrome からホーム画面へインストールして、ネイティブアプリと同じように全画面で使う。

## Samsung Notes との違い

| | Sumi Note | Samsung Notes |
|---|---|---|
| 暗記テープ（答えを隠して指でタップしてめくる） | ✅ | ― |
| 赤シート（オレンジ/赤の字と暗記マーカー部分が消える） | ✅ 画面上で動かせる | ― |
| 忘却曲線の復習（ページ単位、1日→3日→…で自動出題） | ✅ | ― |
| 過去問タイマー（京大工学部の試験時間プリセット） | ✅ | ― |
| 学習時間の記録（書いていた時間を日別に集計） | ✅ | ― |
| 就寝リマインダー＋夜間の暖色フィルター | ✅ | ― |
| 参照ビュー（左に問題PDF、右に解答ノートを並べて書く） | ✅ アプリ内で左右分割 | ― |
| PDF 取り込み・書き込み・PDF 書き出し（手書きはベクター） | ✅ | ✅ |
| 取り込んだ PDF の本文・入力した文字の全文検索、PDF のしおり（目次）から章へジャンプ | ✅ | ― |
| 音声録音、Galaxy AI（ノートアシスト・数式ソルバー） | ― | ✅ |

AI・録音は Samsung Notes の領分。こっちは**受験で点を取るための道具**に振り切っている。
同期はなく、データの持ち出しはバックアップファイル（`.sumi`）で行う。

## インストール（初回だけ）

1. GitHub のこのリポジトリで **Settings → Pages → Build and deployment → Source を「GitHub Actions」** にする。
2. **Actions タブ → 「CI & Deploy」の最新の実行 → Re-run all jobs**（以後はリポジトリの既定ブランチへの push で自動的にテスト・公開される）。
3. Galaxy Tab S11 の **Chrome** で `https://s70rm3892.github.io/Note/` を開く。
4. Chrome のメニュー（︙）→「**アプリをインストール**」（または「ホーム画面に追加」）。
   以後はホーム画面のアイコンから全画面で起動し、**オフラインでも動く**。更新があると画面上部に「更新」ボタンが出る。

> 低遅延描画（`desynchronized` キャンバス）など Chrome の機能を前提に作っている。Chrome で使え。

### S ペンの設定のコツ
- **ボタンを押しながら書く → 消しゴム**（設定で「投げ縄」にも変更可）。
- ペンを画面に近づけてボタンを押すと Air command が開く端末設定になっていることがある。邪魔なら端末の S ペン設定で Air command をボタンで開かないようにする。

## 使い方

### ジェスチャー
| 操作 | 動作 |
|---|---|
| S ペン | 書く（パームリジェクション：ペンが近くにある間は手のひら・指を無視） |
| 指1本ドラッグ | スクロール（慣性あり） |
| 指2本ピンチ | 拡大縮小（100% で軽く吸着） |
| **指2本タップ / 3本タップ** | 元に戻す / やり直し |
| 指1本タップ（テープの上） | 暗記テープをめくる／戻す |
| ペンを止める（約0.45秒） | 図形補正。直線は止めた後もペンを動かすと端点が追従 |
| 同じツールをもう一度タップ | ツールの詳細設定（ペン種類・太さ・色・消しゴムモードなど） |

指で書きたい場合は 設定 → 指で書く。

### ツール
- **ペン**：ボールペン / 万年筆（筆圧で強弱）/ サインペン / 鉛筆。
- **マーカー**：インクの下に塗られる（乗算合成）。一番右の濃い緑は **暗記マーカー**：黒字の上に引くと赤シートで字が消える。
- **消しゴム**：部分消し（線を途中で切る）/ 線ごと消し。暗記テープも消せる。
- **投げ縄**：囲んで選択、またはタップで1つ選択。ドラッグで移動、角で拡大縮小、上の丸で回転（15°刻みで吸着）、**別のページへドラッグすると移動**。メニューから削除・切り取り・コピー・複製・色変更・**テープで隠す**。
- **テキスト**：タップして入力（キーボード・S ペンの手書き入力どちらも可）。
- **暗記テープ**：答えの上をなぞって貼る。指でタップするとめくれる。

### ページ
- 縦スクロール / 横めくり（メニューで切替。横めくりは指を離すとページに吸着）。
- テンプレート：無地 / 横罫 / 方眼 / ドット / コーネル / 左右分割、間隔 4〜10mm、紙色 4種、サイズ A4・B5・A4横・16:10。
- ページ一覧（右上の田アイコン）：タップで移動、ドラッグで並べ替え、⋯ で挿入・複製・削除・復習に追加。PDF にしおりがあれば上に**目次**が出て章へ飛べる。
- **全文検索**：ライブラリの検索欄に2文字以上入れると、取り込んだ PDF の本文とテキストツールの文字からページを探す（全角/半角は区別しない）。手書き文字は検索できない。
- 画像の挿入・カメラ撮影、PDF ページの挿入。
- **参照ビュー**（ツールバーの左右分割アイコン）：左に別のノート（過去問 PDF など）を読み取り専用で表示。左側はペンでもスクロールでき、書き込まれない。境目をドラッグで幅を変更。ノートごとに記憶され、次に開いたときも復元される。

## 受験での使い方（京大工学部情報学科を想定）

1. **過去問演習**：問題 PDF を「PDF取込」→ 解答用ノートを開いて**参照ビューで問題 PDF を左に表示** → タイマーで「京大 数学 150′」等を選んで開始（開始するとツールバーに格納される）→ 右に解答を書く。PDF に直接書き込んでもいい。終わったら「PDFで書き出し」。
   - プリセットは令和7年度 一般選抜 学生募集要項の工学部の個別学力検査の時間（国語90分・数学150分・外国語120分・理科180分）。**毎年の募集要項で必ず確認しろ。**
2. **暗記**：答えはオレンジ（#ff6a00）で書く → 赤シートで隠して自分をテスト。教科書の写真を挿入して暗記テープ／暗記マーカーを使うのも有効。
3. **復習**：覚えたいページを「復習に追加」→ ライブラリの「今日の復習」から出題。テープは全部隠れた状態で出るので、答えを思い出してからめくり、「もう一回 / 難しい / 普通 / 簡単」で自己採点。間隔は自動で伸びる（SM-2 系のアルゴリズム）。
4. **寝る**：就寝時刻（初期値 23:00）を過ぎると上部に警告と暖色フィルター。睡眠中に記憶が定着することは研究でも示されている（Diekelmann & Born, *Nature Reviews Neuroscience* 11, 114–126, 2010）。

## データとバックアップ

- ノートは**この端末の中（ブラウザの IndexedDB）にだけ**保存される。自動保存。永続化（自動削除されない）を要求している。
- アプリのアンインストールや「サイトデータの削除」で**全部消える**。ライブラリ右上 ⋯ →「バックアップを書き出す」で `.sumi` ファイルを Google ドライブ等に保存しておけ。指定日数（初期値7日）バックアップしていないとライブラリに警告が出る。
- `.sumi` はノート単位でも書き出せる（共有用）。取り込みは ⋯ →「バックアップ / .sumi を取り込む」。
- Android の共有メニューから PDF・画像を Sumi Note に送ると、新しいノートとして取り込まれる（インストール後）。

## 開発

```bash
npm ci
npm run dev          # 開発サーバー
npm test             # ユニットテスト（Vitest）
npm run test:e2e     # E2E（Playwright。Tab S11 相当の 1280×800・DPR2、S ペン/マルチタッチを CDP でエミュレート）
npm run build        # dist/ に出力（Service Worker の precache 一覧も生成）
```

構成：

- `src/core` — データモデル、筆跡ジオメトリ（筆圧円の外接線による輪郭）、図形認識、部分消しゴム、復習スケジューラ、Undo
- `src/editor` — ビューポート、描画（ページ単位のビットマップキャッシュ＋深いズーム時のベクター描画、PDF の部分高解像度描画）、低遅延ライブレイヤー（`desynchronized` キャンバス＋予測点）、入力（パームリジェクション、ジェスチャー）、各ツール
- `src/store` — IndexedDB、設定、バックアップ（zip）
- `src/pdf` — pdf.js（CJK cmap 同梱でオフライン表示）、pdf-lib による書き出し
- `src/study` — 赤シート、タイマー、学習時間
- `src/app` — 画面（ライブラリ、エディタ、ダイアログ）

CI（`.github/workflows/ci.yml`）は型チェック → ユニット → ビルド → E2E を実行し、既定ブランチなら GitHub Pages に公開する。
