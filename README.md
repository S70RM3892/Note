# Sumi Note（墨ノート）

Galaxy Tab S11 と S ペンで**受験勉強をする**ための手書きノートアプリ。
Samsung Notes にない「覚える・解く・復習する」機能を中心に作った。
**APK（Android アプリ）** として入れるのが本命。同じものを PWA（Chrome からインストールする Web アプリ）としても使える。

## Samsung Notes との違い

| | Sumi Note | Samsung Notes |
|---|---|---|
| 暗記テープ（答えを隠して指でタップしてめくる） | ✅ | ― |
| 赤シート（オレンジ/赤の字と暗記マーカー部分が消える） | ✅ 画面上で動かせる | ― |
| 忘却曲線の復習（ページ単位、1日→3日→…で自動出題） | ✅ | ― |
| 過去問タイマー（京大工学部の試験時間プリセット） | ✅ | ― |
| 学習時間の記録（書いていた時間を日別に集計） | ✅ | ― |
| 就寝リマインダー＋夜間の暖色フィルター | ✅ | ― |
| 参照ビュー（左に問題PDF、右に解答ノートを並べて書く） | ✅ アプリ内で左右分割 | ― |
| PDF 取り込み・書き込み・PDF 書き出し（手書きはベクター） | ✅ | ✅ |
| 取り込んだ PDF の本文・入力した文字の全文検索、PDF のしおり（目次）から章へジャンプ | ✅ | ― |
| **紙を撮影 → ベクター化**（影を消して文字・図を輪郭線に変換。拡大しても劣化しない、PDF でもベクターのまま） | ✅ 黒＋色ごとのレイヤー | 写真として貼るだけ |
| **固定**（置いた写真・スキャンは自動で固定され、投げ縄・消しゴムに反応しない） | ✅ | ― |
| 音声録音、Galaxy AI（ノートアシスト・数式ソルバー） | ― | ✅ |

AI・録音は Samsung Notes の領分。こっちは**受験で点を取るための道具**に振り切っている。
同期はなく、データの持ち出しはバックアップファイル（`.sumi`）で行う。

## インストール

### A. APK（おすすめ）

1. Galaxy Tab で **https://github.com/S70RM3892/Note/releases/latest/download/SumiNote.apk** を開いてダウンロード。
2. ダウンロードした `SumiNote.apk` をタップ →「この提供元のアプリを許可」→ インストール。
3. 既定ブランチへの push ごとに CI が自動でビルドして Releases に置く。更新は同じ手順で上書きインストール（**下の署名鍵を設定してあれば**ノートはそのまま）。

APK 版だけの機能：
- **スキャナーで撮影**（Google ML Kit ドキュメントスキャナー）：紙の輪郭を自動検出して撮影・台形補正・影や指の除去まで端末内で済ませ、そのままベクター化に回す。カメラ権限はアプリに不要（Google Play 開発者サービスが担当）。
- **S ペンのボタンを押しながら書くと消しゴム**（ブラウザ版では不可。上記）。
- 戻るジェスチャーでメニュー → ダイアログ → ライブラリの順に閉じる。全画面表示（端からスワイプでバーが一時的に出る）。
- 他のアプリの「共有」「アプリで開く」から PDF・画像を受け取って新しいノートにする。PDF/バックアップは「他のアプリに送る」か「ファイルとして保存」を選べる。

#### 署名鍵（最初に1回だけ設定しておけ）

Android は**同じ鍵で署名された APK しか上書き更新させない**。鍵を設定していない間は CI がビルドのたびに使い捨ての鍵で署名するので、更新するには「バックアップを書き出す」→ アンインストール → 新しい APK → 取り込み が必要になる（アンインストールでノートは消える）。上書き更新できるようにするには、PC（または Termux）で鍵を作り、リポジトリの **Settings → Secrets and variables → Actions** に4つ登録する：

```bash
keytool -genkeypair -keystore sumi-release.jks -storetype PKCS12 -alias sumi \
  -keyalg RSA -keysize 4096 -validity 36500 -dname "CN=Sumi Note"
base64 -w0 sumi-release.jks   # 出力全体を SUMI_KEYSTORE_B64 に
```

| Secret | 値 |
|---|---|
| `SUMI_KEYSTORE_B64` | 上の base64 |
| `SUMI_KEYSTORE_PASSWORD` | keytool で決めたパスワード |
| `SUMI_KEY_ALIAS` | `sumi` |
| `SUMI_KEY_PASSWORD` | 同じパスワード（PKCS12 は共通） |

`sumi-release.jks` とパスワードはリポジトリに入れず、自分だけが見られる場所に保管しろ（なくすと次から上書き更新できない。公開リポジトリに置くと誰でも「更新版」を名乗る APK を作れてしまう）。

### B. PWA（Chrome から）

1. GitHub のこのリポジトリで **Settings → Pages → Build and deployment → Source を「GitHub Actions」** にする。
2. **Actions タブ → 「CI & Deploy」の最新の実行 → Re-run all jobs**（以後はリポジトリの既定ブランチへの push で自動的にテスト・公開される）。
3. Galaxy Tab S11 の **Chrome** で `https://s70rm3892.github.io/Note/` を開く。
4. Chrome のメニュー（︙）→「**アプリをインストール**」（または「ホーム画面に追加」）。
   以後はホーム画面のアイコンから全画面で起動し、**オフラインでも動く**。更新があると画面上部に「更新」ボタンが出る。

> 低遅延描画（`desynchronized` キャンバス）など Chrome の機能を前提に作っている。Chrome で使え。

> APK と PWA は保存場所が別。PWA で書いたノートは「バックアップを書き出す」→ APK で取り込む。

### S ペンの設定のコツ
- **ボタンを押しながら書く → 消しゴム**（設定で「投げ縄」にも変更可）。**APK 版のみ**：Chrome（と PWA）はボタンを押したままのペン操作を文字選択に使ってページに渡さないので、ブラウザでは効かない。APK はその操作を消しゴムのペンとしてページに渡し直している。
- ペンを画面に近づけてボタンを押すと **Air command** が開く端末設定になっていることがある（Samsung の機能）。邪魔なら端末の S ペン設定で Air command をボタンで開かないようにする。

## 使い方

### ジェスチャー
| 操作 | 動作 |
|---|---|
| S ペン | 書く（パームリジェクションは下記） |
| 指1本ドラッグ | スクロール（慣性あり） |
| 指2本ピンチ | 拡大縮小（100% で軽く吸着） |
| **指2本タップ / 3本タップ** | 元に戻す / やり直し |
| 指1本タップ（テープの上） | 暗記テープをめくる／戻す |
| ペンを止める（約0.45秒） | 図形補正。直線は止めた後もペンを動かすと端点が追従 |
| 同じツールをもう一度タップ | ツールの詳細設定（ペン種類・太さ・色・消しゴムモードなど） |

指で書きたい場合は 設定 → 指で書く。

**パームリジェクション**（何重にもかけてある）：
1. 指・手のひらでは**そもそも書けない**（初期設定）。インクが出るのは S ペンだけ。
2. ペンが画面の上に浮いている間と、離してから 0.45 秒は**指のタッチを全部無視**（スクロールもしない）。
3. ペンが触れた瞬間、進行中の指のスクロール・ピンチを打ち切る。
4. ペンを使った直後 0.9 秒は2本指・3本指タップ（元に戻す/やり直し）を受け付けない（手のひらが2点に割れて誤 Undo になるのを防ぐ）。
5. 接触面が大きいタッチ（手のひら）は無視。OS がキャンセルしたタッチ（`pointercancel`）も破棄。

### ツール
- **ペン**：ボールペン / 万年筆（筆圧で強弱が大きい）/ サインペン（一定幅）/ 鉛筆（黒鉛のザラつき）。書いている途中の線も確定後と同じ見た目で、低遅延レイヤーに描く。
- **マーカー**：インクの下に塗られる（乗算合成）。一番右の濃い緑は **暗記マーカー**：黒字の上に引くと赤シートで字が消える。
- **消しゴム**：部分消し（線を途中で切る）/ 線ごと消し。暗記テープも消せる。
- **投げ縄**：囲んで選択、またはタップで1つ選択。ドラッグで移動、角で拡大縮小、上の丸で回転（15°刻みで吸着）、**別のページへドラッグすると移動**。メニューから削除・切り取り・コピー・複製・色変更・**テープで隠す**。
- **テキスト**：タップして入力（キーボード・S ペンの手書き入力どちらも可）。
- **固定**：投げ縄で選んで「固定」。固定したものは投げ縄・消しゴム・テキストに反応せず、上から普通に書き込める。投げ縄で固定したものをタップすると「固定を解除して選択 / このページの固定をすべて解除」が出る（右上に錠前マーク）。**挿入した画像・スキャンは、位置を決めて外をタップした時点で自動で固定**（設定で切替可）。
- **暗記テープ**：答えの上をなぞって貼る。指でタップするとめくれる。

### ページ
- 縦スクロール / 横めくり（メニューで切替。横めくりは指を離すとページに吸着）。
- テンプレート：無地 / 横罫 / 方眼 / ドット / コーネル / 左右分割、間隔 4〜10mm、紙色 4種、サイズ A4・B5・A4横・16:10。
- ページ一覧（右上の田アイコン）：タップで移動、ドラッグで並べ替え、⋯ で挿入・複製・削除・復習に追加。PDF にしおりがあれば上に**目次**が出て章へ飛べる。
- **全文検索**：ライブラリの検索欄に2文字以上入れると、取り込んだ PDF の本文とテキストツールの文字からページを探す（全角/半角は区別しない）。手書き文字は検索できない。
- 画像の挿入・カメラ撮影、PDF ページの挿入。
- **写真をベクターで取り込む**（ツールバーのスキャンアイコン / ライブラリの「スキャン」）：撮影（APK はスキャナー）または画像を選ぶ → 四隅を合わせる（自動検出あり）→ 白黒ベクター / カラーベクター / 写真のまま を選び、「線の拾い方」で薄い鉛筆まで拾うか調整 → **このページに配置**（大きさを決めて外をタップで固定）／**PDF で保存**（ベクター PDF）／**新しいノートにする**。影・照明ムラは自動で消え、赤ペンなどの色は別レイヤーになる（赤シートも効く）。
- **参照ビュー**（ツールバーの左右分割アイコン）：左に別のノート（過去問 PDF など）を読み取り専用で表示。左側はペンでもスクロールでき、書き込まれない。境目をドラッグで幅を変更。ノートごとに記憶され、次に開いたときも復元される。

## 受験での使い方（京大工学部情報学科を想定）

1. **過去問演習**：問題 PDF を「PDF取込」→ 解答用ノートを開いて**参照ビューで問題 PDF を左に表示** → タイマーで「京大 数学 150′」等を選んで開始（開始するとツールバーに格納される）→ 右に解答を書く。PDF に直接書き込んでもいい。終わったら「PDFで書き出し」。
   - プリセットは令和7年度 一般選抜 学生募集要項の工学部の個別学力検査の時間（国語90分・数学150分・外国語120分・理科180分）。**毎年の募集要項で必ず確認しろ。**
2. **暗記**：答えはオレンジ（#ff6a00）で書く → 赤シートで隠して自分をテスト。教科書の写真を挿入して暗記テープ／暗記マーカーを使うのも有効。
3. **復習**：覚えたいページを「復習に追加」→ ライブラリの「今日の復習」から出題。テープは全部隠れた状態で出るので、答えを思い出してからめくり、「もう一回 / 難しい / 普通 / 簡単」で自己採点。間隔は自動で伸びる（SM-2 系のアルゴリズム）。
4. **寝る**：就寝時刻（初期値 23:00）を過ぎると画面左下に警告が出て、暖色フィルターがかかる。睡眠中に記憶が定着することは研究でも示されている（Diekelmann & Born, *Nature Reviews Neuroscience* 11, 114–126, 2010）。

## データとバックアップ

- ノートは**この端末の中（APK はアプリ内、PWA は Chrome の IndexedDB）にだけ**保存される。自動保存。
- アプリのアンインストールや「サイトデータの削除」で**全部消える**。ライブラリ右上 ⋯ →「バックアップを書き出す」で `.sumi` ファイルを Google ドライブ等に保存しておけ。指定日数（初期値7日）バックアップしていないとライブラリに警告が出る。
- `.sumi` はノート単位でも書き出せる（共有用）。取り込みは ⋯ →「バックアップ / .sumi を取り込む」。
- Android の共有メニューから PDF・画像を Sumi Note に送ると、新しいノートとして取り込まれる（APK は「アプリで開く」も可）。

## 開発

```bash
npm ci
npm run dev          # 開発サーバー
npm test             # ユニットテスト（Vitest）
npm run test:e2e     # E2E（Playwright。Tab S11 相当の 1280×800・DPR2、S ペン/マルチタッチを CDP でエミュレート）
npm run build        # dist/ に出力（Service Worker の precache 一覧も生成）

# APK（JDK 17+ と Android SDK。ANDROID_HOME を設定）
npm run build && cd android && ./gradlew assembleRelease   # → app/build/outputs/apk/release/app-release.apk
```

構成：

- `src/core` — データモデル、筆跡ジオメトリ（筆圧円の外接線による輪郭）、図形認識、部分消しゴム、復習スケジューラ、Undo
- `src/editor` — ビューポート、描画（ページ単位のビットマップキャッシュ＋深いズーム時のベクター描画、PDF の部分高解像度描画）、低遅延ライブレイヤー（`desynchronized` キャンバス＋予測点）、入力（パームリジェクション、ジェスチャー）、各ツール
- `src/store` — IndexedDB、設定、バックアップ（zip）
- `src/pdf` — pdf.js（CJK cmap 同梱でオフライン表示）、pdf-lib による書き出し
- `src/study` — 赤シート、タイマー、学習時間
- `src/app` — 画面（ライブラリ、エディタ、ダイアログ、スキャン）
- `src/scan` — 写真 → ベクター（Web Worker）：射影変換、紙の色の推定による影除去、ヒステリシス二値化、色相ヒストグラムで色分け、輪郭追跡（穴あり）→ 単純化・平滑化 → SVG パス
- `src/platform.ts` — APK のネイティブ連携（`window.SumiNative`）。ブラウザでは何もしない
- `android/` — Kotlin の薄いシェル：WebView（`WebViewAssetLoader` で `https://appassets.androidplatform.net` から dist を配信）、ML Kit ドキュメントスキャナー、保存/共有、「アプリで開く」、S ペンのボタン、戻る

CI（`.github/workflows/ci.yml`）は型チェック → ユニット → ビルド → E2E を実行し、既定ブランチなら GitHub Pages に公開、APK をビルドして Releases（タグ `apk`）に置く。
